# DartsAnalyticsApp

DARTSLIVE HOMEのCOUNT-UPを中心に、投擲結果・着弾位置・4方向のスマートフォン動画・グリップ写真・用具情報を統合して投擲フォームとグルーピングを分析し、改善実験まで行うローカル中心の分析アプリ。

## 動画撮影

4本を基本とする。

1. 正面・全身
2. 利き腕側面・全身
3. 反対側面・全身
4. 遠景・投擲位置からボードまで全体

不足する場合は追加撮影する。
