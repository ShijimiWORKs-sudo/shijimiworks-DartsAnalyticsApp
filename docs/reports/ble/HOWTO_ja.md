# DARTSLIVE HOME BLE実機検証 手順書（§3）

最終更新: 2026-09-17

このセッションにはBluetoothハードウェアが無く、あなたのPC上でコマンドを
実行する手段も無いため、この検証はあなた自身に実施していただく必要が
あります。以下は、最初のユーザー確認（Windows Bluetooth設定での
ペアリング可能状態への準備）に続けて、機械的な観測作業を自動化した
スクリプトを使う手順です。

## 事前準備

1. DARTSLIVE HOME本体の電源を入れ、ペアリング可能な状態にする
   （指示書§3の「最初のユーザー確認」）。
2. Windows PC側でBluetoothがオンになっていることを確認する
   （設定 → Bluetoothとデバイス）。
3. **通常のWindows Bluetooth設定でのペアリングは不要**です。今回のBLE
   GATT観測はWindowsのペアリング画面を経由せず、専用スクリプトから
   直接BLE通信を行います（多くのBLE周辺機器は、いわゆる「ペア設定」
   画面には表示されないことがあります）。

## 手順

PowerShellを開き、以下を実行してください：

```powershell
cd "C:\制作データ\20_DartsAnalyticsApp"
python -m venv .venv
.venv\Scripts\activate
pip install bleak
python scripts\ble_investigate.py
```

スクリプトが以下を順に行います：

1. **10秒間のBLEスキャン**：周辺のBLEデバイス一覧が表示されます。
   DARTSLIVE HOMEらしき名前（またはそれに近い名前）が見つかるか
   確認してください。**見つからない場合もそれ自体が重要な結果**です
   （指示書§3の「デバイス非表示」に該当）— その場合は`skip`と入力して
   終了してください。
2. 見つかった場合は番号を入力して接続します。
3. 接続できたら、GATTサービス・特性（characteristic）の一覧と、
   read可能な値の現在値を自動取得・表示します。
4. notify（通知）可能な特性があれば自動的に購読します。
5. 以下の7つのタイミングで、実際にその操作を行った直後にEnterキーを
   押すよう促されます（指示書§3のデータ観測タイミングそのもの）：
   - 接続直後
   - 投げる前
   - 1投後
   - 3投後
   - CHANGE後
   - ラウンド変更時
   - ゲーム終了時
6. 一連の観測が終わったら、同じ手順をもう一度繰り返すか聞かれます。
   **できれば2〜3回繰り返してください**（指示書§3「同じ試験を複数回
   行い、再現性を確認する」）。
7. 最後に`ble_investigation_<日時>.json`と`.txt`の2ファイルが
   カレントディレクトリに生成されます。

## 終わったら

生成された2つのファイル（`.json`と`.txt`）を、この開発セッション
（Claude/Cowork）に送ってください。次回のセッションでこのログを解析し、
実際のプロトコル構造（サービスUUID、特性UUID、通知データのバイト列の
意味等）を、**推測ではなく観測結果に基づいて**まとめます。

## うまくいかなかった場合

途中でエラーが出たり、デバイスが見つからなかったり、接続できなかったり
しても、**そこで生成されたログファイルはそのまま送ってください**。
「どの段階で失敗したか」自体が指示書§3が求める分類
（デバイス非表示／ペアリング不可／接続不可／GATT取得不可／データ通知
なし／データはあるが意味不明）に対応する重要な情報です。

`pip install bleak`が失敗する場合（社内ネットワーク制限等）は、その
エラーメッセージも教えてください。別の方法（例：スマートフォンの
「nRF Connect」アプリでの手動確認）に切り替えることも可能です。

## このスクリプトが行わないこと（安全性について）

- ペアリングPIN・パスワード・認証情報は一切収集・送信しません。
- 取得したデータをどこにも自動送信しません（ローカルファイルに保存する
  のみ）。
- 受信したnotifyデータの意味を一切推測・解釈しません（生のバイト列を
  そのまま記録するだけです）。
